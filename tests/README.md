# 结构模拟测试

`tests/structure.test.ts` 在 Node 里运行真实的 `StructureEngine`：用确定性时钟替换
`requestAnimationFrame` / `performance.now`，并用内存 `localStorage` 跑存档流程。

```bash
npx tsx tests/structure.test.ts
```

覆盖的场景：

- 材质悬挑差异（木梁 4 格、砖 1 格、沙 0 格）
- 拆掉支柱后相连部分失去支撑、预警倒计时、坍塌与落地
- 扫描进行中加固，旧分析结果不会覆盖新结构
- 加固可取消预警；但普通编辑不能无限拖延倒计时
- 仅几何合规但超载（玻璃柱顶重石板）同样会坍塌
- 坍塌不回收材料，手动拆除才回收
- 存档包含坠落中的方块；读取后继续下落并重新分析，不会冻结在半空
- 危险区域跟随角色所在列，一键撤离后预警解除
- 同列坠落方块互相堆叠、落地不重叠；砸中角色的方块碎裂且不回收
- 断线式存档：半空存档读回后，最终占位与未中断运行完全一致
