# 方屿 Blockhaven

需要 Node.js 22。

安装：`npm ci`

本地启动：`npm run dev`，打开终端显示的地址。

Docker 启动：`docker compose up --build`，打开 http://localhost:8111。

结构测试：`npm test`（在 Node 中驱动真实的坍塌引擎，见 `tests/README.md`）。

## 结构模拟

方块不再只是静态几何体，每种材质都有各自的悬挑跨度、重量和承载能力：

| 材质 | 悬挑 | 单块重量 | 承载上限 |
| --- | --- | --- | --- |
| 橡木 | 4 | 0.7 | 45 |
| 砖块 | 1 | 1.3 | 50 |
| 岩石 | 1 | 1.6 | 60 |
| 玻璃 | 1 | 0.8 | 18 |
| 沙地 | 0 | 1.0 | 12 |
| 树叶 | 3 | 0.35 | 30 |

- **支撑**：接触地面、坐在受支撑方块上，或从受支撑方块横向悬挑不超过材质跨度。
  沙地永远不会悬挑，木梁可以跨过 4 格，砖、石、玻璃只能跨 1 格。
- **承重**：每块方块承担自身与上方结构的重量，载荷沿立柱向下、沿悬臂回到锚点。
  超过承载上限的方块会让整个它所支撑的部分一起垮塌，所以玻璃柱顶不动石制楼板。
- **坍塌**：失稳方块先进入红色预警（倒计时 + 危险列高亮），倒计时结束后离开网格成为
  坠落体，落回最高的实心表面后重新进入结构并触发一次新的承重检查。
- **撤离**：角色位于坠落列下方时界面会出现危险提示，按 `X` 或点击「撤离」自动移动到安全位置。
- **回收**：只有手动拆除才返还材料；坍塌、砸中角色而碎裂的方块都不返还。
- **分步分析**：分析按 400 格一片、每帧 2 片推进，20k 方块的世界也不会卡住主线程；
  分析期间的加固会让旧结果作废并重新扫描，旧坍塌计算不会覆盖新结构。
- **存档**：只保存方块、物品、角色和正在下落的方块（含速度），不保存「稳定」结论。
  读档后重新分析，半空结构会继续坠落而不是被冻结成静止模型。
